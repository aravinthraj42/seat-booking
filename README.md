## Installation

To set up the application locally, follow these steps:

1. **Clone the repository**:
   
   - git clone hhttps://github.com/aravinthraj42/seat-booking
   -  Open the project in your preferred code editor.
   - cd seat-booking
   - npm install
   - npm run dev 
    - (or)   
    - Open index.html in your browser to see the live preview.

## Usage
- Viewing Seats: Navigate to the grid container to view available seats.
- Selecting Seats: Click on individual seats to select or reserve them.
- Interacting with UI: Use buttons for actions such as confirming reservations.
- Custom Footer: The footer can be modified to display your contact information and portfolio links.


## Technologies Used
- React: Javascript Library
- JavaScript: For any interactive features and DOM manipulations.
- Vite: Template for fast loading
- CSS3: Styling and responsive design.
- HTML5: Structure of the application.
- Flexbox/Grid: Layout management and item positioning.
- Modern Responsive Techniques: Media queries, CSS transitions, and animations for seamless user interactions.

## Customization
- Feel free to customize the following aspects of the application:

- Color Scheme: Modify the CSS variables in index.css to change primary, secondary, and background colors.
- Footer: Update the footer section with your personal details and portfolio links.
- Grid Items: Adjust the number and layout of seats/items as needed by tweaking the grid container and items.
- Responsive Breakpoints: Expand or contract the media queries to adjust behavior on different screen sizes.
